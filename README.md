# Экзаменационный онлайн-тренажёр: ПМ.01

Современный интерактивный веб-сайт для подготовки к экзамену по профессиональному модулю **ПМ.01**.
Содержит **161 уникальный вопрос** с вариантами ответов и одним правильным ответом (без повторений), составленный на основе экзаменационных билетов.

---

## 📁 Где сохранён проект

Проект находится на вашем компьютере по адресу:
```
C:\Users\User\Desktop\exam_quiz_site
```

### Структура файлов проекта:
- `index.html` — главная страница тренажёра (интерфейс, структура сайта).
- `style.css` — стили оформления (адаптивный дизайн, тёмная и светлая темы, плавная анимация).
- `app.js` — логика тренажёра (проверка ответов, таймер, навигация, статистика, шпаргалка).
- `questions.js` — база всех 161 вопросов в формате JavaScript (работает локально без веб-серверов).
- `questions.json` — база вопросов в формате JSON.
- `README.md` — подробная инструкция по запуску и выгрузке на GitHub.

---

## 🚀 Как запустить сайт на компьютере (Локально)

Сайт полностью автономен и не требует установки Node.js, веб-серверов или баз данных:
1. Откройте папку `C:\Users\User\Desktop\exam_quiz_site` на Рабочем столе.
2. Дважды кликните по файлу **`index.html`**.
3. Сайт мгновенно откроется в вашем браузере (Chrome, Edge, Yandex, Firefox, Opera) и будет работать на 100%.

## 🌐 Как загрузить проект на GitHub и опубликовать в интернете (GitHub Pages)

Чтобы ваш сайт был доступен в интернете с любого компьютера или телефона, выполните следующие простые шаги:

### Шаг 1. Создайте репозиторий на GitHub
1. Перейдите на сайт **[GitHub.com](https://github.com/)** и войдите в свой аккаунт (или зарегистрируйтесь).
2. В правом верхнем углу нажмите кнопку **`+`** и выберите **«New repository»** (Новый репозиторий).
3. В строке **Repository name** укажите имя репозитория, например: `exam-pm1` или `quiz-site`.
4. Обязательно оставьте переключатель на **Public** (Публичный).
5. Галочки у пунктов *«Add a README file»* ставить **не нужно**.
6. Нажмите зелёную кнопку **«Create repository»**.

---

### Шаг 2. Загрузите файлы сайта в репозиторий

Вы можете выбрать **любой из двух способов**:

#### Способ А: Через браузер (Самый простой — без команд и терминалов)
1. На странице только что созданного репозитория найдите строчку:
   *«...or push an existing repository from the command line»*, а чуть выше неё ссылку:
   👉 **«uploading an existing file»** (загрузить существующие файлы).
2. Откройте папку на Рабочем столе: `C:\Users\User\Desktop\exam_quiz_site`.
3. Выделите файлы:
   - `index.html`
   - `style.css`
   - `app.js`
   - `questions.js`
   - `questions.json`
   - `README.md`
4. Перетащите их мышкой в окно браузера в область загрузки.
5. Внизу страницы нажмите зелёную кнопку **«Commit changes»**.
6. Файлы загружены!

#### Способ Б: Через терминал Git
Если у вас установлен Git:
1. Откройте PowerShell в папке проекта:
   ```bash
   cd "C:\Users\User\Desktop\exam_quiz_site"
   git init
   git add .
   git commit -m "Первая версия тренажера ПМ.01"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН_GITHUB/ИМЯ_РЕПОЗИТОРИЯ.git
   git push -u origin main
   ```
*(Замените `ВАШ_ЛОГИН_GITHUB` и `ИМЯ_РЕПОЗИТОРИЯ` на свои данные).*

---

### Шаг 3. Включите бесплатный хостинг GitHub Pages
1. На странице вашего репозитория перейдите в верхнюю вкладку **⚙️ Settings** (Настройки).
2. В левом боковом меню найдите раздел **Pages** (в блоке *Code and automation*).
3. В поле **Source** (или *Build and deployment*) выберите: **«Deploy from a branch»**.
4. В выпадающем меню **Branch**:
   - Выберите ветку: **`main`**
   - Папку: **`/(root)`**
   - Нажмите кнопку **Save** (Сохранить).
5. Подождите 1–2 минуты, пока GitHub соберёт сайт.
6. Обновите страницу настроек **Pages**. Вверху появится зелёная плашка с вашей персональной ссылкой:
   ```
   https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/
   ```
7. Готово! По этой ссылке сайт доступен вам, вашим одногруппникам и преподавателям с любых устройств!

## 🌟 Возможности тренажёра

- **161 уникальный вопрос:** Полный охват всех тем экзамена ПМ.01 без повторов.
- **Два режима прохождения:**
  - 💡 **Режим «Обучение»:** мгновенная проверка ответа (зелёный/красный индикатор) с отображением верного варианта.
  - ⏱️ **Режим «Экзамен»:** тестирование с таймером, скрытыми ответами и выставлением оценки по 5-балльной шкале в конце.
- **Работа над ошибками:** возможность в 1 клик запустить тест только по тем вопросам, где были допущены ошибки.
- **Быстрая интерактивная навигация:** плитка с номерами вопросов (1–161) для мгновенного перехода к любому вопросу.
- **🔍 Встроенная шпаргалка / поиск:** мгновенный поиск по базе вопросов прямо во время работы с сайтом.
- **🌓 Тёмная и светлая темы:** комфортно готовиться в любое время суток (выбор сохраняется автоматически).
- **📱 Полная адаптивность:** работает на смартфонах, планшетах и компьютерах.
- **⌨️ Управление с клавиатуры:** клавиши 1-5 или A-E для выбора ответа, стрелки влево/вправо и Enter для перехода.
