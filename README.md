# Экзаменационный онлайн-тренажёр: ПМ1 и ПМ2

Современный интерактивный веб-сайт для подготовки к экзаменам по профессиональным модулям:
- **💻 Модуль ПМ1** (Архитектура ПК, ОС, диагностика, сети) — **161 уникальный вопрос**
- **🎨 Модуль ПМ2** (Компьютерная графика, 2D/3D моделирование и дизайн: Photoshop, Blender, Krita, GIMP, SketchUp, Tinkercad) — **169 уникальных вопросов**

Вопросы между предметами **не перемешиваются**: каждый модуль выбирается отдельно через удобный переключатель на главном экране.

---

## 📁 Где сохранён проект

Проект находится на вашем компьютере:
`
C:\Users\User\Desktop\exam_quiz_site
`

### Файлы проекта:
- index.html — главная страница тренажёра (с переключателем ПМ1 / ПМ2, мобильной адаптацией и тестами).
- style.css — стили оформления (мобильный SaaS-стиль, светлая/тёмная тема).
- pp.js — логика приложения (переключение предметов, таймер, проверка ответов, работа над ошибками, шпаргалка).
- questions.js — единая база данных по ПМ1 и ПМ2 в формате JavaScript (работает локально и на GitHub Pages).
- questions.json — база вопросов в формате JSON.
- README.md — документация и инструкция.

---

## 🚀 Как запустить сайт локально

Дважды кликните по файлу **index.html** в папке C:\Users\User\Desktop\exam_quiz_site. Сайт сразу откроется в браузере.

---

## 🌐 Как обновить сайт в репозитории на GitHub

1. Откройте ваш репозиторий на [GitHub.com](https://github.com/denturbo555/ExamPM1).
2. Нажмите кнопку **«Add file»** (вверху справа) -> **«Upload files»**.
3. Откройте папку C:\Users\User\Desktop\exam_quiz_site на Рабочем столе.
4. Выделите все **6 файлов** (index.html, style.css, pp.js, questions.js, questions.json, README.md) и перетащите их в окно браузера.
5. Нажмите зелёную кнопку **«Commit changes»**.
6. Через 1 минуту сайт на GitHub Pages обновится со всеми новыми вопросами и выбором предметов!
